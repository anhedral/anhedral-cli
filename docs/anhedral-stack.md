# Stack diagram

The [README](https://github.com/anhedral/anhedral-cli#readme) shows the progressive scaffold and all additions.
[Stack standard](stack-standard.md) owns architecture; [capabilities](capabilities.md)
owns composition and acceptance.

Artwork source and regeneration instructions live in
[docs/assets/ARTWORK.md](https://github.com/anhedral/anhedral-cli/blob/main/docs/assets/ARTWORK.md).
The diagram follows Next.js → Hono → Drizzle/D1 + Better Auth, with optional
storage, services and clients. WXT owns the Chrome Side Panel entrypoint.
