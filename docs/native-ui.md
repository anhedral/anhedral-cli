# Archived native port

The exhaustive Anhedral shadcn-to-React-Native port is retired. Its assets, generator, dependency set, test harness and parity tooling are no longer part of the active CLI. Existing generated applications remain consumer-owned and are not rewritten.

The current MVP generates a web application with [shadcn defaults](ui.md). Expo and native UI are not current CLI additions. If Expo returns after MVP, React Native Reusables is the intended native default rather than a separate Anhedral UI layer. Do not restore the archived port or its parity gates to implement that future direction.
