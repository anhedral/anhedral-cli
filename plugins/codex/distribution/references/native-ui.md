# Native UI compatibility

Current Expo setup and source ownership are described in [UI commands](ui.md).
Anhedral UI uses React Native Reusables with a small reviewed extension registry.

The prior exhaustive native port is retained as compatibility source. Its
[development reference](https://github.com/anhedral/anhedral-cli/blob/main/docs/agent-notes/legacy-native-ui.md)
records the earlier component work, not current device acceptance. Existing
consumers and Platform artifacts retain their explicit reviewed pins.
